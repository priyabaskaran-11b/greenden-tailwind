🌿 Greeden – Plant Store Website
This project is a front-end website for a plant store called Greeden, developed using HTML5 and Tailwind CSS. The goal of this project is to create a modern, responsive, and visually appealing e-commerce-style interface for browsing and exploring plant products.

✨ Features
Responsive navigation bar with active page highlighting
Attractive hero section with call-to-action buttons
About section showcasing services and features
Best seller section with hover effects
Dedicated product page with:
Search bar UI
Product cards with hover animations
Sale badges and ratings
“Add to Cart” buttons (UI design)
Contact page with a clean and modern form layout
Promotional banner sections for offers
Customer reviews section with rating display
Newsletter subscription section
Structured footer across all pages

🛠️ Technologies Used
HTML5
Tailwind CSS

🎯 Purpose
This project was created as part of a full-stack development course to practice building real-world, multi-page website layouts and improve UI/UX design skills using Tailwind CSS.

📚 Key Learnings
Designing responsive layouts using Tailwind CSS
Creating reusable UI components and consistent design
Building multi-page navigation (Home, Product, Contact)
Enhancing UI with hover effects, badges, and ratings
Improving visual hierarchy and spacing for better user experience
